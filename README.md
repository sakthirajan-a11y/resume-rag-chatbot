# Resume RAG Chatbot

A Retrieval-Augmented Generation (RAG) based chatbot that extracts and answers $

## 🚀 Features
- Upload a resume PDF
- Extract text using PDF parser
- Ask questions about the resume
- Uses RAG pipeline for contextual answers

- Python
- LangChain
- PyPDF
- Olama
- Streamlit
- Vector Embedding
